# Florin Neagu — Portfolio Site

Site-ul meu personal (portofoliu).

## Cu ce e făcut

- **Next.js** – framework-ul principal (React)
- **TypeScript** – JavaScript 
- **Tailwind CSS** – stiluri
- **Framer Motion** – animații
- **React Hook Form + Zod** – formularul de contact și validarea lui
- **Lucide / React Icons** – iconițe

## Cum pornesc proiectul

```
npm run dev     # pornește site-ul local (localhost:3000)
npm run build   # build de producție
npm run start   # rulează build-ul de producție
npm run lint    # verifică codul cu ESLint
```

## Unde găsesc lucrurile

```
src/app/          -> paginile site-ului
src/components/   -> bucățile de UI (hero, formular, etc.)
src/data/         -> textele și datele (profil, traduceri)
public/images/    -> pozele
```
